# Support

Use GitHub Discussions for usage questions, design discussion, and sharing
workflows. Use GitHub Issues for reproducible bugs and scoped feature requests.
Use private vulnerability reporting for security concerns.

Include the DMLPact version, operating system, PostgreSQL version, statement
class, relevant flags, stable reason code, and a redacted minimal reproduction.
Never post passwords, connection strings, private SQL/data, or unredacted
receipts.

This is a community-maintained project with no guaranteed response time or
production support SLA. If an apply result is `uncertain`, stop automated
retries and reconcile the target database with an operator.
